How DeCodon Works?

Quick guide to datasets, physics models, and AI agent mechanisms.

Technical Overview
Dataset & UniProt API

Pulls live data from the UniProt REST API every 2 weeks (bypassing stale cache). Uses 300 positive proteins (known condensate formers) and 300 negative proteins (soluble cytosolic proteins) to train and ground the model.

Live ML Classifier

Powered by Scikit-Learn (sklearn) Random Forest & Gradient Boosting classifiers, originally inspired by open-source INRIA Research Institute & Google Summer of Code biophysics packages.

Gemini AI Agent

Uses the Google Gemini API (`gemini-2.5-flash`) to synthesize physics feature shifts into 3 clear findings: droplet stiffening mechanism, motor neuron toxicity, and therapeutic drug rescue strategies.

Interactive User Selections

Whatever protein and mutation you select instantly recomputes 6 biophysical forces and generates tailored mechanistic findings.

Biological Glossary

• TDP-43 / FUS / Tau: Key human proteins that form liquid droplets in healthy neurons.
• ALS: Amyotrophic Lateral Sclerosis; fatal motor neuron paralysis disease.
• Alzheimer's: Neurodegenerative memory loss driven by Tau protein aggregation.
• DNA: Double-helix genetic blueprint stored inside cell nuclei.
• RNA: Single-stranded messenger transcribed from DNA to build proteins.
• Codon: A 3-letter genetic triplet code that translates into 1 amino acid.
